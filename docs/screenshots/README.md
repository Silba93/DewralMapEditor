# Screenshot checklist

Add the following PNG files to this directory. Keep the filenames exact so the
links prepared in the root README do not need to change.

## `editor-overview.png`

- Recommended size: 1600x900 or 1920x1080.
- Use the GitHub-style theme.
- Open a visually interesting map and keep the item palette visible.
- Show the main toolbar, document tabs, floor/zoom status, and map canvas.
- Do not include personal paths, usernames, debug consoles, or Task Manager.
- README alt text: `Dewral Map Editor with an OTBM map open`

This is the hero image directly below the README introduction.

## `startup-client-profile.png`

- Recommended size: at least 1100x700.
- Show the startup window with one standard profile and one custom profile.
- Client paths should be cropped, blurred, or point to a neutral example
  directory.
- README alt text:
  `DME startup window with a configured custom client profile`

This image belongs in the **Client profiles** subsection.

## `brushes-and-palettes.png`

- Recommended size: 1600x900 or larger.
- Show a map being edited with a terrain or doodad palette open.
- Keep brush size controls and the active editing mode visible.
- README alt text:
  `Editing terrain with brushes and item palettes in DME`

This image belongs in the **Brushes and palettes** subsection.

## `ingame-preview.png`

- Recommended size: 1600x900 or larger.
- Enable in-game preview and place the player in a recognizable interior or
  outdoor area.
- Keep enough editor chrome visible to make it clear this is DME.
- README alt text:
  `Walking through an OTBM map in DME in-game preview mode`

This image belongs in the **In-game preview** subsection.

## Inserting the images

Each screenshot slot in the root README contains the final Markdown line as an
HTML comment. After adding a PNG, replace the nearby placeholder sentence with
that Markdown line and remove the corresponding comment.
